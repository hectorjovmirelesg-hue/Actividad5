# CHANGELOG - Actividad 5

## Registro de cambios del proyecto

Este documento registra las modificaciones, avances y resultados obtenidos durante el desarrollo del proyecto de Machine Learning con MLflow.

## Versión 0.1.0 - Estructura inicial

### Archivos creados
- `README.md`: documentación general del proyecto.
- `CHANGELOG.md`: registro de cambios y reporte de resultados.
- `fuentes/datos_prep.py`: archivo destinado a la preparación y limpieza de datos.
- `fuentes/train.py`: archivo destinado al entrenamiento y registro de experimentos.
- `fuentes/entrena.ipynb`: notebook para Google Colab.
- `datos/datos_ini/`: carpeta para almacenar los datos originales.
- `datos/datos_limp/`: carpeta para almacenar los datos procesados.

### Decisiones técnicas
- Se seleccionó el dataset público Breast Cancer Wisconsin (Diagnostic).
- Se utilizarán Regresión Logística y Random Forest.
- Se aplicará validación cruzada de cinco particiones.
- Se utilizará GridSearchCV para optimizar hiperparámetros.
- Se registrarán experimentos mediante MLflow.
